# Klick'r v4.0.5.23

本版重点：稳定执行、避免重复点击、方便定位脚本失败原因。

## 新增功能

- **点击后确认**：点击一次后等待目标条件连续两帧满足再继续，确认失败停止场景，不自动重复点击。入口：点击动作配置底部。
- **智能滑动查找**：先检查目标，再按设定间隔滑动，找到即停，最多 1–50 次。入口：滑动动作配置底部。
- **运行历史与诊断导出**：保存最近 20 次运行、每次最近 500 个已完成动作和最多 5 张失败截图，支持 ZIP 导出。入口：场景首页 → 更多选项 → 运行历史。

## 稳定性修复

- 修复截图缺失被误判为目标消失、子流程沿用旧截图的问题。
- 修复长子流程和长等待被外层超时提前截断的问题，保留取消与循环调用保护。
- 连续失败按整个事件统计，避免前置成功动作清除失败计数。
- 缺失计数器不再按 0 比较；Android 拒绝动作时返回实际失败。
- 补齐动作目标引用的复制、导入修复，以及旧备份中等待和断点配置的保留。

## 升级与兼容

- 新增可选功能默认关闭，普通点击和滑动保持原有用法。
- 贴边入口大小、悬浮菜单和暂停按钮布局不变。
- 数据库自动升级到 27；升级前建议导出场景备份，直接覆盖安装，不要卸载旧正式版。
- 推荐下载 `universal-release.apk`，兼容手机和模拟器；也可选择对应架构的小体积安装包。
- Debug 测试版与正式版是两个独立应用，需通过场景备份转移测试版里的脚本。
- 诊断数据仅保存在本机，不自动上传；分享 ZIP 前请检查截图中的私人信息。

## 验证范围

发布准备阶段已通过 992 项本地单元测试、31 项 Android 识别测试（另 1 项样本生成测试按原设计跳过），Debug 构建与 Lint 门禁通过。发布流程还会重新执行测试门禁并构建签名 Release APK。自动化回归不等同于真实游戏长时间运行验证。
