# Klick'r v4.0.5.24

版本日期：2026-09-27。

本版重点是长时间运行的内存控制、资源清理和退出诊断，不新增第三方依赖，不增加数据库迁移。

## 稳定性优化

- 图片模板缓存改为 Java 最大堆的 1/8，封顶 32 MiB；按实际分配容量计费，避免大量小模板低估内存。
- 截图使用独立单缓冲复用，关闭或尺寸切换时解除旧引用；缓存清理不提前回收仍在识别中的图片。
- 调试报告使用单个后台写入任务，队列同时限制条数与字节数，单事件明细也有限额。磁盘过慢或写入失败时取消本次报告，不拖垮场景执行，也不把残缺报告标成完整。
- 加强截图会话、旋转切换、原生检测器和服务停止时的资源清理与异常处理。
- 悬浮菜单停止后取消未完成的尺寸更新，避免窗口销毁后的回调异常；不扩大贴边热区，不改变已确认的菜单布局。
- 补齐运行异常提示的现有语言资源，保留完整 Lint 发布检查。

## 更完整的退出诊断

- 每次运行开始及此后约每 30 秒记录内存状态，保留最近 120 条采样并落盘，长等待期间也继续记录。
- 记录应用版本、包名、PID、Java/Native/PSS 内存、图片缓存和设备总内存状态，不采集其他应用进程列表。
- 诊断包附带可读系统退出原因、运行结束与清理状态，以及调试报告完成/过载/写入失败等状态。
- 出现问题可从“场景首页 → 更多选项 → 运行历史”导出诊断 ZIP。诊断数据仅保存在本机，不自动上传；分享前请检查私人信息。

## 下载与升级

- 不确定设备架构时下载 **`Klickr-4.0.5.24-universal-release.apk`**；其余四个 APK 是对应架构的精简包。
- 使用本仓库原正式包名与发布签名，升级前先备份场景，直接覆盖旧正式版，**不要卸载或清除数据**。
- 之前的 `.debug` 独立测试版与正式版不共享数据，请通过场景备份转移脚本。上游/商店版本签名可能不同，不能保证直接覆盖。
- 不改变图片、文字、数值、颜色的识别算法、匹配阈值、点击坐标或计数器运算规则。大量模板场景可能增加缓存重新读取次数。
- 校验文件：同页 `SHA256SUMS.txt`。项目对应源码：[v4.0.5.24 标签](https://github.com/slobys/Smart-AutoClicker/tree/v4.0.5.24)，也可下载发布页的 Source code；构建配置和依赖版本包含在源码内。

## 验证与边界

- 发布准备阶段：106 个套件、1037 项本地单元测试通过；相关模块 Lint 与完整 Debug 构建通过。新增回归包括调试回调压力、有界队列、IO 失败、缓存释放、采样上限和服务清理。
- 同一稳定性实现的独立 Debug 测试包在 Google 官方 Android 12L 平板模拟器中完成 5000 次计数器/颜色条件循环，约 4 分 56 秒自然结束；调试窗口与报告开启，PSS 采样约 110–131 MiB。
- 上述模拟器测试不是最终签名 Release APK 的长时间游戏实测，也不是云手机系统内存耗尽复现。发布流程会重新执行单元测试、Lint、Android 识别测试后构建签名 Release APK，实际结果见 [GitHub Actions](https://github.com/slobys/Smart-AutoClicker/actions/workflows/release.yml)。
- 优化降低应用自身内存压力，**不能保证系统或云手机平台在资源不足时不回收进程**，也不代表两天真实游戏稳定性已经验证。
