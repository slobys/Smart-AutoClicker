# Klick'r v4.0.5.25

版本日期：2026-09-29。

本版加入实验性的路线录制与回放，改进精细框选，并修复工具栏靠右时测试结果被挤出屏幕的问题。沿用现有正式包名与发布签名，不新增第三方依赖。

## 测试结果自动向内展开

- 条件测试和事件测试的结果面板会根据工具栏位置自动换向：工具栏靠左，结果向右展开；工具栏靠右，结果向左展开。
- 打开面板、拖动、返回测试窗口及切换屏幕方向时重新计算布局，避免结果跑到屏幕外。
- 切换方向保留现有测试设置，不扩大主悬浮菜单的贴边点击范围。

## 更清楚、少遮挡的框选

- 颜色、数值、文字检测区域和图像截取统一使用细边框、框外小手柄；小选区不再显示遮住目标的大号内部提示。
- 截图预览默认保持原尺寸，不再打开后自动缩小到 80%；图像截取仍可手动缩放和平移。
- 颜色条件保留单像素取色，也可以扩大检测区域。区域模式比较平均颜色，不是寻找区域内任意同色点；旧条件不会自动扩大。

## 路线录制与回放（实验功能）

- 支持可见整数 X/Y 坐标定位，或固定方向、固定缩放、玩家标记居中的滚动小地图定位；保存路径点，不录制视频或原始手指操作。
- 支持点击地面及固定摇杆短按移动，通过 A/B 两个不同方向校准移动关系；A/B 不是路线起点与终点。
- 支持从起点附近自动接近、在终点附近沿原路返回，以及在智能场景动作中调用已保存路线。
- 减少短直线上密集路径点造成的反复停顿，保留拐点、折返、终点和位置确认；回放不保证与手动行走等速。
- 补齐载入、保存、校准、回放前检查和结束反馈，分别提示地图不匹配、X/Y 未识别、遮挡、无新画面和等待连续确认。
- 保留定位丢失、卡住、超时、换图和屏幕尺寸变化等保护，不会自动绕障碍或探索随机地图。

入口、配置步骤及限制请先阅读[路线使用指南](https://github.com/slobys/Smart-AutoClicker/blob/v4.0.5.25/documentation/route-recorder-zh.md)。请先在安全的短路线测试，不要直接用于长时间无人值守任务。

## 下载与升级

- 不确定设备架构时，下载 **`Klickr-4.0.5.25-universal-release.apk`**；另提供四种架构的精简包及 `SHA256SUMS.txt`。
- 本仓库旧正式版可覆盖升级，升级前先导出场景备份，**不要卸载或清除数据**。本版包含数据库 27→28 升级，用于保存“执行路线”动作；不建议直接降级安装旧版。
- `.debug` 测试版与正式版数据独立，场景需通过备份导出、导入转移。上游／应用商店版本可能签名不同。
- **路线文件目前仅保存在本机，不随场景备份导出。** 场景备份只保存路线 ID；从测试版或其他设备迁移后，需要重新录制／配置路线并重新选择，不能把场景备份当作路线备份。
- 本版对应源码：[v4.0.5.25 标签](https://github.com/slobys/Smart-AutoClicker/tree/v4.0.5.25)，也可下载发布页的 Source code；保留原项目版权与 GPL 许可证。
