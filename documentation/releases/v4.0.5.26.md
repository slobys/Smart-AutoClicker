# Klick'r v4.0.5.26

版本日期：2026-10-12。

本版汇总 v4.0.5.25 之后已完成的脚本管理、识别与运行稳定性改进，并包含本次已由用户测试确认的语言确认按钮修复。沿用现有正式包名与发布签名，不新增运行时第三方依赖。

## 更明显的语言选择与精细框选

- 新建文字条件默认简体中文；已有条件和复制条件保留原语言，模型未安装时仍需下载。
- 语言页底部改为实心圆角主按钮，带勾号和“确定并返回”，沿用主题配色及按压反馈。
- 点击后显示“正在应用…”，成功提示并返回条件页；失败时显示具体原因并允许重试。关闭或返回不应用暂选语言，整个条件仍需在条件页保存。
- 统一最小选区的像素取整、有效性校验和裁剪，修复同样大小移动后勾号时亮时灰的问题；保存期间不接受选区回调重新启用确认。

## 图片、文字、数值与颜色识别

- 修复横竖屏捕获像素与检测缩放链路，保留完整屏幕捕获后在本地缩放检测帧，减少旋转、竖屏与小目标的坐标和像素误差。
- 修复缩放输出与模板缓存共用像素的问题，避免连续测试时模板被后续画面污染、结果从高分突然变为零。
- 图片匹配增加受限的缩放、前景结构和颜色校验；文字与数值共享彩色分离、背景抑制及逐行处理，中文文字按目标字符置信度检查；数字明确使用 Latin 模型。
- 颜色区域可选择覆盖率判断或“区域内找色”；旧条件不自动启用找色模式，不扩大已保存的选区，也不降低用户设定的阈值。
- 改进作用于公共检测器，不针对某个脚本或游戏关键词。每次使用当前帧，不用旧结果伪造本帧命中。

完全遮挡、严重运动模糊和极小字符仍可能漏检，复杂背景也可能误判；这些改进不保证所有游戏每帧识别成功。建议限定检测区域，重要动作结合“点击后确认”。详见[动态识别说明](https://github.com/slobys/Smart-AutoClicker/blob/v4.0.5.26/documentation/dynamic-recognition-zh.md)。

## 测试范围与颜色预览

- 测试时始终显示固定检测范围，将范围与实际命中位置区分；细结果边框不再额外扩大保存的选区或盖住目标。
- 单像素颜色使用中心透明标记；区域颜色避免在识别范围内绘制彩色结果，降低标记干扰下一帧的风险。
- 单个颜色条件测试提供同帧小块像素放大窗、目标／采样颜色、RGB 值与坐标。未命中时明确标注范围中心，不冒充命中点。
- 退出测试会清理预览并取消尚未启动的测试。工具栏、放大窗仍请放在目标之外，悬浮窗并非完全不会进入屏幕捕获。

## 脚本管理与运行稳定性

- 切换脚本改为紧凑双列布局，突出当前脚本、智能／简单选中状态，以及取消按钮反馈。
- 悬浮工具栏支持直接新建并编辑脚本，无需关闭当前脚本再返回首页；打开创建窗口先暂停，取消后不会自动恢复运行。
- 新建脚本可选择已有分组或输入名称自动建组；场景页支持批量删除，确认前列出目标，失败项可重试。删除不可撤销，重要脚本请先备份。
- 修复脚本加载期间暂停后仍可能启动的问题；Android 已接收手势但回调结果不明时不自动补点，避免重复点击。增加繁忙设备的回调等待余量，不会因普通识别未命中而停止检测。
- 未保存捕获范围偏好的用户默认请求整个屏幕；设置可关闭，已保存偏好不被覆盖。系统授权及“屏幕共享中”等系统隐私提示仍保留。

## 路线录制与回放仍为实验功能

- 保留录制路线的转弯与折返，并按记录路径原路返回；A/B 只用于校准两个方向的移动关系，不是路线起终点。
- 手势完成不再等同于角色已移动，必须观察位置进展；地面点击不移动时只做有界的同方向较近点击尝试，持续失败会暂停。
- 不自动穿墙、跳过转角、扩大到达半径或改写已有路线；不支持随机地图探索、旋转小地图或动态摇杆。真实游戏的遮挡和路径可达性仍需单独验证。

## 下载、升级与数据

- 不确定架构时下载 **`Klickr-4.0.5.26-universal-release.apk`**；另提供 arm64-v8a、armeabi-v7a、x86、x86_64 包及 `SHA256SUMS.txt`。
- 正式包名为 `com.buzbuz.smartautoclicker`，沿用旧正式版签名。升级前导出场景备份，直接覆盖安装，**不要卸载或清除数据**。
- 蓝色图标 `.debug` 测试版与正式版数据独立，需用场景备份导出／导入转移，不能直接共享数据。
- 本版相对 v4.0.5.25 不新增数据库迁移；从更早版本升级仍会执行既有迁移，不建议直接降级。
- **路线文件不包含在场景备份中**，从测试版或其他设备迁移后需重新配置路线并在动作中选择，不能把场景备份当作路线备份。
