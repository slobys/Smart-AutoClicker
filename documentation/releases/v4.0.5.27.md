# Klick'r v4.0.5.27

版本日期：2026-10-13。

本版包含用户测试确认的结果框显示调整。沿用现有正式包名与发布签名，不新增运行时第三方依赖。

## 更醒目的单层结果框

- 图片、文字、数值测试恢复放大的结果框：命中为绿色，未命中为红色。
- 移除内部白色细框、黑色对比描边和四角标记，只保留一层结果框；等待、空结果或清空时也不残留内框。
- 单条件测试与屏幕事件测试使用相同显示；颜色的白色范围、空心取样标记、像素放大预览及区域内部保护保持不变。
- 线宽为 10 个物理像素，线条中心每边向外留白 20 个物理像素。显示框看起来更大，**不代表实际检测区域变大**：保存选区、模板、阈值及识别算法均不变，设置页的框选边线和手柄也不变。
- 保留对目标内部、相邻结果及颜色区域的绘制保护。放大框和工具栏仍可能进入屏幕捕获、覆盖附近内容；必要时移动工具栏或使用眼睛按钮隐藏标记。

## 下载、升级与数据

- 不确定架构时下载 **`Klickr-4.0.5.27-universal-release.apk`**；另提供 arm64-v8a、armeabi-v7a、x86、x86_64 包及 `SHA256SUMS.txt`。
- 正式包名为 `com.buzbuz.smartautoclicker`。升级前导出场景备份，直接覆盖安装，**不要卸载或清除数据**。
- 蓝色图标 `.debug` 测试版与正式版的数据独立，需导出／导入场景备份转移。
- 本版相对 v4.0.5.26 不新增数据库迁移，不改写已有场景或路线。**路线文件不包含在场景备份中**。

## 验证与边界

- 发布准备时本地构建通过，147 个 JVM 测试套件、1,393 项测试，0 失败／错误／跳过；全项目 30 份 Lint 报告为 0 错误，结果显示模块与应用分别保留 6、16 个既有警告。
- 结果框原生像素回归 27 项，覆盖红绿样式、等待／空结果／清空、三种图片搜索模式、移动命中、横竖屏、高密度屏幕、相邻结果及混合颜色保护；用户已确认测试版无问题。
- 发布标签通过 [Release 工作流](https://github.com/slobys/Smart-AutoClicker/actions/workflows/release.yml)执行完整 JVM 测试、Lint、Android 图片与 OCR 测试（包括准备简体中文模型后的强制中文组），通过后才构建、签名并发布正式 APK。
- 本次调整显示效果，不承诺提高识别精度，也不改变子任务或智能滑动的执行逻辑。自动化测试不等于所有真机游戏或长时间运行验证。
