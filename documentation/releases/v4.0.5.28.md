# VisionClick v4.0.5.28

版本日期：2026-10-13。

这是首个以 **VisionClick** 名称发布的正式版，基于本仓库 Klick'r v4.0.5.27 的功能继续开发。使用独立包名，可与旧版并存；不是旧 Klick'r 的覆盖更新。本次不新增运行时第三方依赖，不改变已有的图片、文字、数值、颜色识别和动作执行逻辑。

## 下载与安装

- 不确定设备架构时，下载 **`VisionClick-4.0.5.28-universal-release.apk`**。
- 另提供 arm64-v8a、armeabi-v7a、x86、x86_64 包和 `SHA256SUMS.txt`，支持 Android 7.0（API 24）及以上。
- 正式版名称为 **VisionClick**，包名为 `com.slobys.visionclick`；`com.slobys.visionclick.debug` 是独立测试版，不是本页的正式包。
- 本仓库的 `fDroid` 是无广告构建变体，不代表已经在 F-Droid 或 Google Play 商店上架。

## 名称、图标与仓库

- 应用名称、权限引导、通知、快捷设置和内置教程中的用户可见品牌统一为 VisionClick。
- 使用新的手机触控图标，收紧外围留白；调整 Android 自适应图标前景比例，消除额外深色边带。提供 Android 7 多密度图标和 Android 13 单色主题图标，不同桌面的遮罩外观可能不同。
- GitHub 仓库改名为 [slobys/VisionClick](https://github.com/slobys/VisionClick)，README、下载与反馈入口同步更新。旧标签和旧 APK 保留原样，不以新名称替换历史附件。
- 安装包名与内部源码命名空间分离；通知设置、教程和组件跳转使用当前安装身份，通知操作限定当前应用，避免影响并存的旧版或测试版。

## 旧版数据迁移

1. 先在旧 Klick'r 或 VisionClick 测试版中导出场景备份，保留原应用和数据。
2. 安装 VisionClick 正式版，重新授予无障碍、悬浮窗、通知及屏幕捕获权限。
3. 导入场景备份，核对截图选区、坐标和运行结果；不要让新旧应用同时操作屏幕。

**新包名不自动共享旧版数据。路线不包含在场景备份中，需要单独迁移；不要卸载旧应用或清除数据来尝试强制迁移。** 后续 VisionClick 正式版在包名和发布签名一致时可覆盖升级。

## 验证与边界

- 发布准备时本地全量 JVM 验证通过：148 个测试套件、1,409 项测试，0 失败／错误／跳过；30 份 Lint 报告为 0 错误、92 个既有警告，Debug 构建通过。16 项品牌回归覆盖新包名、组件、教程、通知隔离、Android 7/8/13 图标及自适应图标像素边缘。
- 发布标签由 [Release 工作流](https://github.com/slobys/VisionClick/actions/workflows/release.yml)执行完整 JVM、Lint、Android 图片与 OCR 测试，包含准备简体中文模型后的强制中文测试组；通过后才构建、签名和发布正式 APK。
- 编译、原生渲染与模拟器测试不能代替真实设备上的桌面显示、授权、场景导入及游戏长期运行验证。本版品牌更换不承诺提高识别精度。
