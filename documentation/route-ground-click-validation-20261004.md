# 地面落点无效与位移确认验证（2026-10-04）

## 证据与修复范围

用户截图显示数字坐标 `(31,165)`，运行条仍显示沿路线移动。截图没有实际派发落点、移动轨迹和退出日志，不能据此断言是牌坊碰撞，也不能断言是 OCR 失败。

代码确认的缺口是：安卓手势完成不代表游戏接受了移动；坐标不变时，旧控制循环可能继续发送相同的地面点击，运行提示不能区分等待移动和卡住。

本次只调整路线地面点击回放及返程：

- 完成手势后等待真实坐标变化，不再把手势回调当作移动成功。
- 在可靠的新观测、角色稳定且至少等待 3 秒的前提下，依次使用原步长、70%、40% 的同方向落点；最多 3 次无位移尝试后暂停。
- 位移至少 1 定位单位、且距目标减少超过 0.5 单位，才重置无位移尝试预算。侧移、后退及小幅噪声不能重置预算。
- 不扩大半径、不横向绕墙、不跳过拐点、不修改已录路径。手势失败／回调未确认或坐标丢失不触发较近落点尝试。
- 运行条显示当前目标、距离、屏幕落点和尝试次数；卡住时显示目标与处理提示。普通事件点击、识别器、录制、方向校准和固定摇杆不使用这套地面落点调整。
