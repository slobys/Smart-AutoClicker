## Google 官方模拟器实测

环境：Small_Tablet、Android 12 / API 32、1920×1200；独立测试地图工具见 [scripts/route-smoke-map](../scripts/route-smoke-map/README.md)。

这些检查经过真实屏幕捕获、原生 OCR 和 Android 无障碍手势，不是仅模拟控制器返回值：

| 检查 | 实际结果 |
| --- | --- |
| 两方向校准 | A 从 `(100,100)` 移动到 `(110,100)`；B 到 `(110,110)`。每次仅发出一次移动，保存的两个校准向量正确 |
| 录制新路线 | 手动移动后保存 3 点：`(100,100) → (110,100) → (110,110)`；原路线保留 |
| 新录路线回放 | 回到起点后按顺序移动两次，到终点显示完成，并停止点击 |
| 暂停与继续 | 刚启动就暂停，等待 5 秒，移动次数仍为 0；继续后到终点 |
| 错误地图 | 标记改为 OTHER MAP 后启动，自动暂停，移动次数为 0 |
| 错误起点 | 在 `(130,100)` 启动，提示起点不符，没有自动移动 |
| 静止画面 | 小活动指示点促使合成器提供新帧，校准可完成；不使用缓存画面凑足确认次数 |
| 右侧控制条 | 修复继承窄主菜单位置后越界的问题，暂停、结束和移动入口均完整可见 |

## 尚未验收的范围

- 用户实际游戏的字体、动态坐标排版、镜头跟随、移动速度及障碍物。
- 固定摇杆在具体游戏上的死区、惯性和拖动响应；当前端到端测试覆盖地面点击模式。
- 长时间、大量路径点回放和云手机性能。
- 无可见坐标的地图、动态摇杆、自动进图触发、路线备份导入、自动绕障：当前不支持。

首次使用应按 [中文教程](route-recorder-zh.md) 在安全空旷区域录一段短路线，验证后再扩大使用范围。
